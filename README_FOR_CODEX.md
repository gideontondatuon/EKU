# PAKET HANDOFF — Dashboard Cashflow EKU

## Cara menggunakan
1. Ekstrak paket ini pada workspace/repository tempat Codex akan bekerja.
2. Salin seluruh teks file `MASTER_PROMPT_CODEX_GPT6_ULTRA_DASHBOARD_CASHFLOW_EKU.md` ke Codex.
3. Beri tahu Codex untuk meninjau folder `references/` terlebih dahulu.
4. Jangan gunakan data dummy sebagai data produksi. Logo BI pada screenshot referensi hanya contoh tampilan, bukan izin penggunaan atau aset logo resmi.
5. Infrastruktur produksi dan publikasi data asli membutuhkan persetujuan lembaga.
